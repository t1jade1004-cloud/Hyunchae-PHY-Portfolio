##  Installation & Setup

To run these notebooks and scripts locally:

1. **Clone the repository:**
   ```bash
   git clone git@github.com:your-username/computational-physics-newman.git
   cd computational-physics-newman
   ```

2. **Create and activate a virtual environment:**
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows use: venv\Scripts\activate
   ```

3. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```
